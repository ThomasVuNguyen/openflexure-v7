# OpenFlexure Microscope: Camera Mounts

The OpenFlexure Microscope supports multiple cameras. They are either used with an microscope objective with RMS thread or their own lens reversed and held at the right distance to the sensor with a lens spacer.

This directory holds the mechanical parts and shapes for these cameras, like mounting points, cut outs, lids, lens spacers, etc

The optical parameters can be found in ``openscad/optics_configurations.scad``.
