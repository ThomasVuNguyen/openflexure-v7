# Low-cost microscope

This is a lower cost version of the OpenFlexure Microscope. It uses the lens from the Raspberry Pi Camera to produce a microscope with field of view about 750×560μm, similar to using a 20x objective. It is motorised, but you can also build it as a manual microscope.
